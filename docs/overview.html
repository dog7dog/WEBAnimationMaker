概要

WEBAnimationMakerは、ブラウザ上で「動きのあるWebページ」を作れる制作ツールです。図形を配置し、ブロックを組んでインタラクションを設定すると、そのまま動くHTML・CSS・JavaScriptとして書き出せます。

WEBAnimationMakerについて

図形やテキストをキャンバスに配置し、「クリックしたら拡大する」「スクロールで見えたらフェードする」のようなインタラクションをブロックで組み立てます。プレビューで動いているものと書き出されるものは同じコードなので、「ツール上では動いたのにコピーしたら動かない」が起きません。

サーバーは不要で、index.html を開くだけで動きます。通常の描画機能に加えて、MODによる拡張やAIアシスタントによるコード生成にも対応しています。

4つのタブ

画面上部のタブで、作業する場所を切り替えます。デザイン → コーディング → キャンバスで確認 → 書き出し、が基本の流れです。

デザイン

図形・テキスト・画像を配置し、色や角度などを編集します。

コーディング

Blocklyのブロックで、トリガー→アクションのインタラクションを組み立てます。

テキストエディタ

生成されたコードを見たり、Canvas API / Three.js のJSを直接書いて実行できます。

キャンバス

生成されたCSS/JSが実DOMでそのまま動くプレビュー。再生バーで途中まで進めて確認できます。

主な機能

デザイン

四角形・円・三角形・多角形・直線・テキスト・画像、ペン/ブラシ/消しゴムでの描画に対応します。

インタラクション

クリック・ホバー・スクロール・キー入力など13種類のトリガーと、拡大・移動・回転・変形など33種類のアクションブロックを組み合わせます。

ページの高さ

キャンバス下端をドラッグして縦長のページを作れます。1ページごとに吸い付くスクロールや、画面に固定する要素にも対応します。

レイヤー

並び替え、表示、ロック、フォルダ分けに対応します。

書き出し

そのまま動くHTML、PNG、プロジェクトファイル(.mlc)として書き出せます。

MOD

ZIP形式のMODから図形・ブラシ・コーディングブロック・UIなどを追加できます。

AIアシスタント

自然言語からCanvas APIやThree.jsのコードを生成できます（4プロバイダーに対応）。

動作環境

  • 最新版のGoogle Chrome、Microsoft Edge、Firefox
  • JavaScriptとIndexedDBが有効な環境
  • MODのZIPインストールやAI機能は、file:// で直接開くと動かないため、 python3 -m http.server などローカルサーバー経由で開くことを推奨します
