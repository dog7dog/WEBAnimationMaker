# WEBAnimationMaker 機能拡張パック

コアの描画・保存・インタラクション機能に加えて、制作全体を底上げする機能を
`AppCore/features/` にまとめています。既存コアには手を入れず、
`redraw()` / `canvasCoords()` などをラップして動作します。

---

## 追加ファイル

```text
AppCore/features/
├ edit_tools.js       ... 複製 / 反転 / z順序 / 整列・分布 / スポイト / パレット管理
├ viewport.js         ... グリッド / スナップ / ズーム・パン
├ command_palette.js  ... コマンドパレット(⌘K) / ショートカット一覧(?)
├ autosave.js         ... 自動保存 & クラッシュ復旧
├ feature_toolbar.js  ... 上記をトップバー/メニューに統合するUI
├ toolbar_overflow.js ... ツールバーに入りきらないボタンを「⋯」に収納
├ image_import.js     ... 画像の挿入（ファイル/ドラッグ&ドロップ/クリップボード）とコピー
├ page_resize.js      ... キャンバス下端ドラッグでのページ高さ変更・ページ区切り線
└ preview_player.js   ... キャンバスタブの再生バー（再生/一時停止/シーク）
```

## 機能一覧

### 🧰 編集ツール（edit_tools.js）
- **複製**（⌘D）— 選択図形を16pxずらして複製。複数選択対応
- **反転** — 選択範囲の中心を軸に左右／上下反転
- **z順序** — 最前面／最背面（複数選択対応）
- **整列** — 左/右/上/下/水平中央/垂直中央（単体はキャンバス基準、複数は選択範囲基準）
- **分布** — 3個以上を水平／垂直に均等配置
- **スポイト**（I）— ネイティブ EyeDropper API 優先、無ければキャンバスクリックで色取得
- **カスタムパレット** — 現在色をパレットに保存（右クリックで削除、`localStorage` 永続化）

### 🔭 ビューポート（viewport.js）
- **グリッド** — 背景に格子と中心線を表示。切り替えはコマンドパレット（⌘K）から
  （キーボードの単独ショートカットは現在ありません）
- **スナップ** — グリッドに図形描画を吸着
- **ズーム**（⌘+ / ⌘- / ⌘0、Ctrl+ホイール）— 25%〜400%、右下にズームバッジ
- **パン**（Spaceキー＋ドラッグ）— キャンバスをスクロール

> オニオンスキン用のメニュー項目（`mpToggleOnion`）が「ツール」メニューに
> 残っていますが、対応する実装が無く現在は動作しません（タイムライン機能の
> 廃止に伴う名残です）。

### ⌘ コマンドパレット（command_palette.js）
- **⌘K** — 全コマンドを検索して実行（↑↓で移動、Enterで実行）
- **?** — キーボードショートカット一覧を表示

### 💾 自動保存 & 復旧（autosave.js）
- 20秒ごと + ページ離脱前に `localStorage` へスナップショット
- 次回起動時、前回の作業を検出したら「復元しますか？」を提案
- ファイルメニューでON/OFF切替（デフォルトON）
- 保存時、ステータスバーに「自動保存」バッジが一瞬光る

### 🖼 画像（image_import.js）
- ファイル選択 / ドラッグ&ドロップ / クリップボードからの貼り付け（⌘V）で画像を挿入
- ブラウザからドラッグした画像・画像URLの貼り付けにも対応
- 選択中の画像をクリップボードへコピー（⌘⇧C）。他のアプリへそのまま貼れる
- 画像は dataURL としてプロジェクトに埋め込まれるため、HTML書き出し後も
  外部ファイルを持ち歩く必要がない

### 📏 ページの高さ（page_resize.js）
- キャンバス下端のバーを下へドラッグして、ページを縦に伸ばせる
  （10px刻み、Shiftで1px刻み、ダブルクリックで一番下の図形に合わせて詰める）
- 「◯ページごとにスクロールしたとき」用の区切り線を表示（画面の高さは左下の
  操作パネルで指定。プレビュー窓の大きさに合わせるボタンつき）
- 1画面ずつピタッと止まるスクロール（吸着）の切り替え
- キャンバスを左右中央に配置

### ▶️ プレビュー再生バー（preview_player.js）
- キャンバスタブに再生/一時停止・最初から再生・シークバーを追加
- ブラウザの `Animation`（`getAnimations()`）を直接操作するため、独自の再生処理を
  持たず、書き出したページと同じ動きを途中まで進めて確認できる
- スクロール連動（`scrollview` / `scrollprogress`）はスクロール位置が進行を
  決めるため対象外

### 🧵 ツールバーの折りたたみ（toolbar_overflow.js）
- `#topbar` / `#editor-topbar` に入りきらないボタン（MODが追加した分を含む）を
  自動的に「⋯」メニューへ収納する

| キー | 動作 |
|---|---|
| ⌘K | コマンドパレット |
| ? | ショートカット一覧 |

## 設計方針

- **コア非改変** — `AppCore/features/` 内で完結。`redraw()` と `canvasCoords()` は
  元の関数を保持したままラップ（他モジュールが直接呼んでも壊れない）
- **依存の存在チェック** — すべての機能は呼び出し前に対象関数の有無を確認するため、
  一部モジュールが無くても致命的エラーにならない
- **永続化は localStorage のみ** — サーバー追加不要。グリッド設定・カスタムパレット・
  ページの高さ・自動保存ON/OFF をブラウザに保存
- **読み込み順** — すべて `app.js` の後に読み込むことで、コアのグローバルが揃った状態で初期化

## 動作要件

- スポイトのネイティブ版は `EyeDropper API` 対応ブラウザ（Chrome/Edge等）。
  非対応時はキャンバスクリック方式に自動フォールバック
- プレビュー再生バーは `Element.getAnimations()` に対応したブラウザが必要
- サーバー側の追加は不要（`app.py` / `ai_api.py` には触れていません。以前のAI
  バックエンドの名残で、現在は起動する必要がありません）
