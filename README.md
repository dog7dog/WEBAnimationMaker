# 🎬 WEBAnimationMaker

**WEBAnimationMaker** は、ブラウザ上で動く「動きのあるWebページ」制作ツールです。

図形やテキストをキャンバスに配置し、ブロックを組み立てて
**「クリックしたら」「スクロールで見えたら」→「拡大する」「フェードする」** のような
インタラクションを設定すると、そのまま動く **HTML + CSS + JavaScript** として書き出せます。

プレビューで動いているものと書き出されるものは同じコードなので、
「ツール上では動いたのにコピーしたら動かない」が起きません。

サーバーは不要で、`index.html` を開くだけで動きます。

# 🧭 4つのタブ

画面上部のタブで、作業する場所を切り替えます。

|タブ|役割|
|----|----|
|🎨 **デザイン**|要素を配置・編集する|
|🧩 **コーディング**|ブロックで動きを組み立てる（Blockly）|
|📝 **テキストエディタ**|生成コードを見る・JSを直接書く（Monaco）|
|🖥 **キャンバス**|生成されたCSS/JSが実DOMでそのまま動くプレビュー（再生バーで途中まで進められます）|

デザイン → コーディング → キャンバスで確認 → 書き出し、が基本の流れです。

# ✨ 主な機能

## 🖌 デザイン

図形

- 四角形（角丸対応）
- 円
- 三角形
- 多角形（辺の数を変更可）
- 直線（破線スタイル対応）
- テキスト（フォント・サイズ指定、ダブルクリックで直接編集）

描画

- ペン
- ブラシ
- 消しゴム

編集

- 選択・移動・リサイズ・回転
- 塗りの色と枠線の色を別々に指定（四角形・円・三角形・多角形）
- 不透明度
- グループ化 / 解除
- 前面へ / 背面へ
- コピー / 貼り付け / 削除
- Undo / Redo
- 定規・スナップ
- キャンバスサイズ / 背景色の変更
- **ページの高さをドラッグで伸ばす** — キャンバス下端のバーを下へ引くと縦長のページになります。
  10px刻み（Shiftで1px刻み）、ダブルクリックで一番下の図形に合わせて詰めます。
  画面に収まらない長さでもスクロールして編集できます。
- **ページの区切り線** — 画面1つ分ごとに線を引き、「2ページ目 / 500px」のように
  折り返す位置とpxを表示します（`◯ページごとにスクロールしたとき` のトリガーと
  合わせて使います）。
- **1ページをプレビューに合わせる** — 左下のモニターのボタンで、別タブのプレビュー窓の
  表示サイズをそのまま1ページ（キャンバスの幅＋区切り線の間隔）にします。
  窓が開いていればその大きさ、開いていなければ画面いっぱいで開いて測ります。
- **ページごとに吸い付くスクロール** — 左下の磁石のボタン。1画面ずつピタッと止まります。
- **画面に貼り付く** — プロパティパネルのチェック。スクロールしても同じ位置に残る
  ヘッダーや追従ボタンが作れます。

画像

- 挿入（ファイル選択 / ドラッグ&ドロップ / クリップボードから貼り付け）
- ブラウザからドラッグした画像・画像URLの貼り付け
- 選択中の画像をクリップボードへコピー（他のアプリへ貼れます）
- 図形と同じようにリサイズ・回転・重ねがけできます

> 画像はdataURLとしてプロジェクトに埋め込まれるので、
> HTML書き出しをしたあとも外部ファイルを持ち歩く必要がありません。

## 🎬 インタラクション（Trigger → Action）

「どの要素で」「何が起きたら」「どの要素を」「どう動かすか」を指定します。
トリガー元と対象を分けて持っているので、
**「ハンバーガーボタンを押したら別のメニューを開く」** のようなケースも作れます。

### トリガー（13種）

|種類|意味|
|----|----|
|`click`|クリックされたとき|
|`dblclick`|ダブルクリックされたとき|
|`hover`|マウスが乗っているあいだ|
|`press`|押しているあいだ|
|`inview`|スクロールして画面に入ったとき|
|`load`|ページが表示されたとき|
|`key`|キーが押されたとき|
|`scroll`|指定した量までスクロールしたとき|
|`scrollpage`|◯ページ（画面1つ分）ごとにスクロールしたとき|
|`timer`|一定の間隔ごと|
|`scrollany`|スクロールするたびに（分岐と組み合わせて使います）|
|**`scrollview`**|**その図形が画面を通り過ぎるのに合わせて（スクロール連動）**|
|**`scrollprogress`**|**ページ全体のスクロールに合わせて（スクロール連動）**|

### アクション（33ブロック）

**アクション** — 状態をひとつ変える

|種類|意味|
|----|----|
|**`変形`**|**別の図形の位置・大きさ・角度にまとめて合わせる（パワポのモーフ風）**|
|`scale`|拡大・縮小|
|`rotate`|回転|
|`move`|移動|
|`skew`|傾け|
|`flip`|左右・上下の反転|
|`fade`|濃さを変える|
|`show` / `hide`|表示 / 非表示|
|`blur`|ぼかし|
|`brightness`|明るさ|
|`grayscale`|白黒|
|`saturate`|鮮やかさ|
|`hue`|色合いのずらし|
|`glow`|影をつける|

**出現** — 見えていない状態から出す

フェードイン / スライドイン / 大きくしながら / ポンと / 回しながら / めくって / ぼやけから

**退場** — 消える

フェードアウト / 縮めて消す / 動かして消す

**ずっと動く** — 繰り返す

ふわふわ拡大縮小 / くるくる回転 / ゆらゆら動かす / 揺らし続ける / 振り子 / 点滅 / 跳ねる /
**線に沿って動かす（軌道）**

> くり返しは **回数**（0でずっと）と **片道 / 往復** を選べます。
> 軌道は、ペンや直線で描いた線をそのまま通り道にします。線はレイヤーパネルで
> 非表示にしておけます。

> 位置を動かすものは、どれも **横◯px 縦◯px** で指定します（横は右が＋、縦は下が＋）。
> 斜めの動きも同じ書き方で作れます。

> **変形**は「AをBの位置・大きさに変形する」と指定します。Bは行き先の目印で、
> レイヤーパネルで非表示にしておけます（位置だけが使われます）。
> 目印を動かせば行き先も追従します。

ずっと動く系は、`load` と組み合わせれば最初からずっと、
`hover` なら乗せているあいだだけ、`click` なら開始 / 停止の切り替えになります。

### ページ操作

指定した要素までスクロール / ページの先頭へ戻る / リンクを開く / ◯秒待つ / 元に戻す

**値ブロック**（数を返します）

- `スクロールしたpx` — 先頭からの距離。先頭は0
- `スクロールしたページ数` — 画面1つ分を1ページとした数。整数 / 小数ありを選べます
- `画面の高さ(px)` — 見る人の画面1つ分の高さ

分岐・繰り返し・変数・関数（Blockly標準）と組み合わせると、
順番に再生する演出や条件つきの動きも作れます。
たとえば「**スクロールするたびに** → もし `スクロールしたページ数` ＝ 1 なら → 拡大する」
のように書けます。値はその時点のものを読むので、**`ページが表示されたとき` と
組み合わせると読み込み時の1回しか判定されません**。スクロールに応じて変えたい場合は
`スクロールするたびに` を使ってください。

### 繰り返し方（toggleMode）

|モード|挙動|既定で使うトリガー|
|----|----|----|
|`once`|一度発火したら、その状態を維持する|`load`|
|`hold`|条件が真のあいだだけ有効。外れたら自動で戻る|`hover` / `press`|
|`toggle`|状態をON / OFFで切り替える|`click` / `dblclick` / `inview` / `key` / `scroll` / `scrollpage` / `timer`|
|`scrub`|時間ではなくスクロール位置で動きが進む|`scrollview` / `scrollprogress`|

> スクロール連動はCSSだけで動きます（`animation-timeline`）。対応していない
> ブラウザ向けには、同じ動きをするJSも一緒に書き出します。
> 「ずっと動く」系や軌道と組み合わせると、スクロールに合わせて線をなぞるような
> 動きも作れます。

それぞれのブロックで、時間・遅れ・**動きの緩急**・**ずらし**を設定できます。
動きの緩急は9種類（なめらか / 一定速度 / **行き過ぎて戻る** / **勢いよく飛び出す** /
**ばねのように揺れて止まる** / **カクカク** など）。
**ずらし**は、対象がグループのときに中身を1つずつ遅らせます
（「カードが0.1秒ずつ順に出てくる」など）。
「ずっと動く」系では、時間の欄が1周にかかる秒数になります。

拡大・回転・移動やぼかし・明るさは種類ごとに別々のCSS変数へ書き出して合成するので、
ひとつの要素に重ねがけできます。同じところを複数のブロックが奪い合っている場合だけ、
コーディングタブに警告が出ます。

## 🌐 Three.js (WebGL) 連携API

- WebGL描画用のキャンバス（`#cv-three`）を併設
- `addObject()` で追加したオブジェクトを、2Dの図形と同じレイヤーパネルで
  表示/ロック/並び替えできる
- `registerThreeRenderer()` で、レイヤーの表示・ロック状態の変化をWebGL側へ通知できる

> Three.js本体は同梱していません。実際にWebGLで描画するMODを別途用意（インストール）
> することで連携します。以前同梱していたサンプルMOD（`webgl_threejs`）は
> 削除済みで、現時点では標準では動きません。

## 🤖 AI

- AIアシスタント（チャット形式）
- 複数プロバイダー対応（OpenAI / Gemini / Claude / Grok を切り替え）
- AIによるCanvas API生成（アニメーションプリセット：星空・花火・雪・炎・波・パーティクル 等）
- AIによるThree.jsコード生成
- 生成コードのプレビュー・危険ワードチェック
- 生成コードの適用 / MOD化 / エディタ送り
- キャンバス画像の添付（Vision）
- 会話履歴・使用統計

サーバーは不要です。ブラウザから各社のAPIへ直接リクエストし、
APIキー・会話履歴・使用統計はブラウザ内（localStorage）に保存します。

### 動作確認状況

ブラウザから直接APIを叩くため、各社がブラウザ由来のリクエスト（CORS）を
許可しているかどうかで動くかが決まります。実際のAPIキーで確認できたものは以下のとおりです。

|プロバイダー|状況|
|----|----|
|Gemini|✅ 確認済み|
|OpenAI|未確認|
|Claude|未確認（ブラウザ直接呼び出し用のヘッダを送っています）|
|Grok|未確認|

「未確認」は動かないという意味ではなく、まだ実キーで試していないという意味です。
試したらこの表を更新してください。接続できない場合は
チャット欄にCORSの可能性を含むエラーが表示されます。

> ⚠ **APIキーの取り扱い**
> キーはブラウザに平文で保存されます。同じブラウザを使える人と、
> このページで動くコード（インストールしたMODを含む）からは読めてしまいます。
> 共有端末では使わず、使い終わったら設定画面から削除してください。
> また `file://` で開くとAPIへのリクエストがブラウザに拒否されるため、
> AI機能を使うときはローカルサーバー経由で開いてください。

## 🔌 MODシステム

WEBAnimationMakerはMODに対応しています。
MODはZIPファイルをローカルからインストールして使います
（ツールバーの「MOD」→「MODをインストール」）。
インストールしたMODはブラウザ内に保存され、次回以降も読み込まれます。
アンインストールすると、確認ののちページが再読み込みされます。

サンプルMODは同梱していません。作り方は下記の MOD SDK を参照してください。

### MOD API

- createLayer()
- registerTool()
- registerBrush()
- registerShapeType()
- addShape()
- registerThreeRenderer()
- registerMod()
- **registerTriggerBlock() / registerActionBlock()** — コーディングタブに独自の
  トリガー・アクションブロックを追加します。既存の種別（クリック・スクロール・
  拡大・移動…）を組み合わせた新しいブロックなので、ツールボックス表示や
  CSS/JS生成にそのまま乗ります。
- libraries.load() / libraries.declare() / libraries.get() / libraries.has() / libraries.list()（外部ライブラリの登録・利用）

# 🚀 起動方法

静的サイトとして動作します。サーバーは不要です。

## そのまま開く

`index.html` をブラウザで開くだけで動きます。

## ローカルサーバー経由で開く（推奨）

一部の機能（MODのZIPインストール、AI機能など）はブラウザの制約で
`file://` では動かないため、簡易サーバー経由を推奨します。

```bash
python3 -m http.server 8000
```

ブラウザで

```
http://localhost:8000
```

を開いてください。

> `app.py` / `ai_api.py`（Flask）は以前のAIバックエンドの名残です。
> AI機能もブラウザだけで動くようになったので、起動する必要はありません。
